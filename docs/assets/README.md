## Capture rules

Keep these honest. They are product documentation, not marketing renders.

- Capture at **1024×635 or larger**, PNG, at the real window size.
- Use the **default dark theme** and no zoom.
- Show the genuine state, including `No model configured` when nothing is configured.
- **Never** capture a window containing an API key, a real customer path, a private repository name,
  or any credential. Open a throwaway project first.
- Do not paint over, annotate, or upscale. If the UI changes, retake the screenshot.

## Replacing them

Overwrite the files in place, keeping the exact filenames above so `README.md` keeps resolving. Then
confirm both images render in the rendered README before pushing.
