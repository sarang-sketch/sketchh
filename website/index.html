Make Sketch code like you

Write your conventions down once. Sketch reads AGENTS.md and CLAUDE.md in your project, turns your own Markdown files into slash commands, and loads a skill when a task needs it.

Skills can get better on your own tasks: Sketch proposes small edits to a skill and keeps one only when your test tasks score higher.

Every run can be undone

Before the agent changes a file, Sketch saves a copy. If you don't like the result, one click puts every file back the way it was. It works without Git.

Prefer to look first? Switch on review mode and each change waits as a diff for you to accept or reject.

A team that hands work to each other

Build Team gives you three chats in the same project: Frontend, Backend and Database. When one needs something from another, it says so in a line like @backend: ... and that chat picks it up.

Hand-offs are capped per message, so two agents can't pass work back and forth forever.

Bring your own tools

Add any MCP server, or paste the config you already use in Claude Desktop or Cursor. Press Test to see its tools before a chat uses them.

A server that comes inside a project you cloned only starts after you approve its exact command. If the project changes it, Sketch asks again.

A full editor around the agent

  • Monaco editor with IntelliSense for TypeScript, JavaScript, JSON, CSS and HTML
  • A real terminal with your own shells: PowerShell, Git Bash, WSL, zsh, bash, fish
  • Git built in: stage, commit, branches, push and pull, with an AI-written commit message
  • Side-by-side diffs against what's staged or committed
  • Search and replace across the project, which you can undo
  • Ghost-text completions and Ctrl+K to rewrite a selection
  • Light and dark themes, or follow your system
  • Ask, Agent and Auto modes that decide what the agent may do without asking

Your code stays yours.

Sketch has no account, no server and no usage tracking. Your code stays on your disk, and your API keys stay in your operating system's credential store. Apart from things you ask for, like a git push, Sketch only talks to the model you picked.

Turn on Offline Mode and Sketch refuses every request that would leave this computer, and lists each request it made.

Free, down to the last request

Sketch itself costs nothing. Run a model on your own computer and every request is free too. Sketch checks your memory and graphics card, recommends a coding model that fits, and downloads it when you say so.

  1. Install Ollama, which is free.
  2. Open Settings, then Models, and pick the model marked Best fit.
  3. Start coding. Your prompts and code stay on your machine.

Questions

Is Sketch really free?

Yes. Sketch is open source under the Apache-2.0 license, with no account and no subscription. With a model on your own computer you pay nothing. If you use a hosted model, you pay that provider for what you use.

Do I need an API key?

No. Ollama, LM Studio and llama.cpp run on your computer and need no key. You can also add a key for OpenAI, Anthropic, Google Gemini, Groq, OpenRouter and more, or sign in with your ChatGPT account.

What does "beta" mean here?

Sketch works and has over 2,000 automated tests, but it is early. Expect rough edges and changes before the launch. When something breaks, tell us on GitHub.

When does Sketch launch?

Soon. Early access is open now, so you can use the beta today. Watch the GitHub repository to hear about the launch first.

Which computers does it run on?

Sketch is built for Windows, macOS and Linux. The early-access download is for Windows today. The beta isn't code-signed yet, so Windows asks you to confirm: choose More info, then Run anyway.

Does the agent run commands on its own?

You choose. Ask mode only reads and explains. Agent mode asks before every command. Auto mode runs ordinary commands, but still asks before anything destructive. Commands never go through a shell, so pipes and chained commands are refused.

Can I use it without the internet?

Yes, with a model on your computer. Turn on Offline Mode and Sketch refuses every request that would leave the machine. Programs you start yourself in the terminal are separate, and Sketch says so.

Can the agent read my secrets?

No. The agent can't read or write .env files or private keys, can't change anything inside .git, and can't edit Sketch's own record of what it did.
